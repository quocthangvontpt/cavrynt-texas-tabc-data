# Data Dictionary

| Field | Meaning |
|---|---|
| entity_legal_name | Legal business or applicant name reported by TABC |
| dba_trade_name | Trade name or DBA, when provided |
| premises_street_address | Proposed licensed premises street address |
| premises_city | City of the premises |
| premises_zip_code | ZIP code, when available |
| county_name | County associated with the premises |
| metro_area | Cavrynt metro-area grouping |
| filing_date | Source-reported filing date |
| source_status | Source-reported status; not proof of opening |
| permit_type | TABC application or permit classification |
| source_dataset | Source dataset identifier |
| source_url | Official source dataset reference |
| source_record_id | Primary source record identifier represented as text |
| source_record_ids | Grouped source identifiers, when applicable |
| application_count_at_premises | Number of applications grouped at the premises |
