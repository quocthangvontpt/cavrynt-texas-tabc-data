# Texas TABC Pending Applications — CSV Schema & Research Guide

This public repository documents the Cavrynt 15-column CSV format for researching recent Texas Alcoholic Beverage Commission (TABC) pending applications.

**[View the Cavrynt dataset and pricing](https://cavrynt.com/?utm_source=github&utm_medium=referral&utm_campaign=tabc_dataset)**

## What is included

- `illustrative_sample.csv`: fictional sample records for testing the CSV schema
- `DATA_DICTIONARY.md`: definitions of the 15 columns
- `SOURCE_AND_LIMITATIONS.md`: official data source and interpretation guidance

The sample is fictional. This repository does not publish the paid weekly dataset.

## Data coverage

The commercial CSV focuses on recent TABC pending applications in selected Texas counties covering the Houston, Dallas–Fort Worth, Austin and San Antonio metro areas.

An application does **not** establish that a business has opened, received a license or will begin operations.

## Official source

Texas Open Data / TABC:
https://data.texas.gov/d/mxm5-tdpj

Cavrynt is an independent data preparation project and is not affiliated with TABC or the State of Texas.
